# homebrew-tap
Homebrew formulas

## git-bs

Interactive Git branch selection in Rust, with fuzzy search and commit previews.

```sh
brew install Bhacaz/tap/git-bs
git bs
```

The formula builds from the [v0.1.0 source release](https://github.com/Bhacaz/git-bs/releases/tag/v0.1.0).
Homebrew provides Rust for the build and Git for running the tool.
